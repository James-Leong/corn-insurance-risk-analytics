# 离线比较运行器

仅消费本地 Parquet；本模块不导入 UQER、不调用网络、不依赖 token。运行前使用项目 Python 3.12 虚拟环境并安装 research 依赖：

```bash
cd backend
.venv/bin/python --version
.venv/bin/python -m research.run --cache ../var/market --output ../var/comparison --run-id corn-2026-v1
```

缓存目录必须含 market.parquet、contracts.parquet、calendar.parquet 和 manifest.json。先逐文件校验 SHA256，日期请求必须严格为 2025-12-31—2026-10-23。报告输出目录可独立挂载到 API 容器；服务器只读取 JSON 结果，无需运行训练或 SDK。相同 run-id 不可覆盖，修改输入或模型后使用新版本 ID。

## 本次有限历史协议

- 具体普通玉米合约、结算价；20个完整交易日回看和之后20个完整交易日观察。无缺失填补、无收盘价替换、无连续合约拼接。
- 为匹配限定时间，使用独立版本 market-terms-20d-v1；不能与此前长期60日回看研究混排。前19个日期仅用于回看，最后20个日期仅用于标签。
- 每个估值日生成保障价为当日结算价95%、100%、105%的三个研究条款，数量100吨、零免赔、无封顶。赔款复用业务规则引擎。合成条款不是真实保单。
- 有效估值日按55%/23%/22%划分训练、独立校准、验证。前分区所有标签结束日必须严格早于后分区首个估值日；跨界记录剔除。同日所有合约条款一起分区。不存在已打开的最终测试集。
- 每个日期总权重相等，当日合约和条款均分。模型训练、校准、主指标均使用该权重。正赔回归仅使用正赔样本。
- 历史基线：当前合约前19个对数收益，5日块，512条20日路径，固定种子42。小历史池不能覆盖极端行情；不发布P90。
- GLM：标准化＋Logistic(C=1)和Gamma(alpha=0.1)。XGBoost：100棵、深度2、学习率0.05、单CPU线程，固定种子42；均值回归平方误差。各方法仅一组预定参数，不搜索验证集赢家。
- 两个监督模型均使用独立校准日期进行sigmoid校准。训练至少15日期、正赔至少10日期；校准至少10日期且触发类别齐全。门槛不足保留失败方法及空成绩，不丢掉目标样本重新排名。这些只是工程拟合下限，不是统计充分性承诺。
- 主指标包括加权赔款RMSE/MAE/偏差及触发Brier；另列可靠性分箱和合约分组误差。价格last/MA20另属价格参照任务，仅提供价格误差与情景赔款。

## 工件和限制

bundle.json 经 API 模型校验后发布，catalog.json 登记完整文件hash。独立的 var/models/<run-id>/ 保存 split-manifest.json、model-artifacts.json 与监督模型joblib工件，先生成工件再发布报告。比较API仅读JSON；新增历史研究估值API按固定清单及hash校验后加载可信模型，使用inference可选依赖，不加载用户上传文件。协议记录输入hash、依赖锁hash、研究源码hash、样本hash与条款。

所有方法固定 research_only。仅一年以内历史，重叠20日标签带来明显依赖；不输出赢家、正式概率有效性、正式业务增益或生产默认模型。尚未提供配对日期块置信区间与长期市场阶段稳定性，因此不能据此执行正式选型。风险个案均为验证集历史估值，不能用于当前保单。模型拟合失败不妨碍展示已完成基线，同时报告标记 incomplete。

## 已训练参数与容器挂载

每个模型目录另保存 parameters.json（特征顺序、GLM标准化参数和系数、截距、概率校准器、库版本与适用域）、XGBoost原生分类/回归JSON，以及 deployment-manifest.json。后者关联既有报告hash、训练时期源码hash、数据版本与所有工件hash，并记录重载预测核验结果。训练工件与可读参数可一起只读挂载；应用读取既有工件不需要 token 或重新训练。模型仍为研究状态，挂载本身不代表获准作为正式客户默认模型。

现有可信joblib可单独补充导出，无需重新训练：

```bash
.venv/bin/python -m research.export_models --models ../var/models/corn-2026-v1 --report ../var/comparison/runs/corn-2026-v1/bundle.json --cache ../var/market
```

导出文件已存在时拒绝覆盖。新运行自动在发布之前完成导出和少量历史个案的重载一致性核验。首次corn-2026-v1属于训练后的补充导出：原报告、原joblib和报告所记训练源码hash保持原样，新增导出脚本hash单独记录，不追改旧报告的来源记录。CPU模型规模很小，不需要GPU服务器。
