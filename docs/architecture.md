# 架构与演进

## 当前 Demo

浏览器 → Vue 3/Vite（农户/合作社/保险机构/农业管理部门业务视角）→ FastAPI `/api/v1` → 用例服务 → 领域计算 + 数据适配器。领域赔付函数不依赖 FastAPI；UQER 与 mock 共用规范化输出。业务界面展示数据来源和模拟标记，SDK 降级原因保留在接口中供技术诊断。

前端通过 `src/workspaces.ts` 配置角色导航与独立试算参数，`src/mockBusiness.ts` 提供项目、成员、保单关联的 Mock 数据和状态流转，`BusinessWorkspace.vue` 展示角色首页、台账、筛选导出与详情操作。模拟申请、审核、支付、成员参保和补贴拨付同步更新各角色汇总，操作状态保存在浏览器中。农业管理部门聚焦覆盖、财政补贴执行和赔付兑现。赔付试算仍调用后端计算接口，过期响应不得覆盖新参数结果。

## 设计边界

- DataAPI SDK 属于可选集成；凭据通过环境变量提供，不写入 Docker 镜像，失败时明确标记回退。
- Mock 使用可复现序列；预测采用简单基线，不能被描述成经过验证的机器学习模型。
- 合同条款以输入参数演示；后续应落为版本化产品规则，增加价格源/单位/观察窗口/免赔额/费率/上限校验。
- 当前角色切换仅用于演示业务流程，前端按演示角色限制可见记录与操作，不提供真实认证或后端权限隔离。Mock 操作状态持久化到本机浏览器，尚无服务端业务持久化；后续加入用户/组织权限以及业务操作审计、数据集版本和情景结果留痕。
