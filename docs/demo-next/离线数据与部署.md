## 已训练模型的保存与复用

`models/corn-2026-v1/`包含：

- `glm_hurdle.joblib`、`xgboost_hurdle.joblib`：完整已拟合模型、标准化与概率校准器。
- `parameters.json`：GLM系数/截距、标准化均值/尺度、校准系数、特征顺序、模型参数、依赖版本和适用域。
- `xgboost_hurdle-classifier.json`、`xgboost_hurdle-regressor.json`：原生XGBoost模型。
- `model-artifacts.json`、`split-manifest.json`、`deployment-manifest.json`：文件hash、切分、数据/源码/依赖来源及重载验证记录。

已用三个历史案例验证重载后的概率、条件均额和预期赔款与原报告一致，XGBoost原生JSON重载也一致；没有重训或改写已发布报告。后续新实验自动执行参数导出。历史分块法没有拟合权重，其块长、路径数、种子和数据规则保存在报告protocol中。

Web的模型评估页读取冻结报告；客户风险分析会从挂载目录加载通过hash校验的模型，对支持的历史研究合同实时计算。只支持冻结验证日期、95%/100%/105%保障比例、零免赔/无封顶的风险条款；免赔与封顶可在压力情景单独调整。没有把research_only工件设为生产默认模型。当前训练使用CPU，XGBoost为100棵深度2的树，Ridge为轻量线性模型；无需显卡。若另开GPU实验，限定单独任务、30分钟以内，主线不等待远端结果。

## 运行与部署

服务器无需配置UQER_TOKEN或安装UQER SDK。完整演示需要inference可选依赖（numpy、pandas、scikit-learn、XGBoost、joblib）加载保存模型；Dockerfile已经安装该extra。库用于推断，Web不导入research训练模块、不重新训练。

1. 把最新演示数据包解压到服务器同一数据目录，保留market、comparison、models、price结构。
2. 复制项目Compose配置并准备镜像。使用`DATA_PROVIDER=parquet`明确要求真实缓存；`DEMO_DATA_DIR`指向服务器数据目录。Compose固定数据起止日期并以只读方式挂载到`/data`。
3. 启动后选择保险机构→玉米行情→C2701→带入客户风险分析→使用演示案例并分析；依次查看风险、压力和报告。模型评估保留为验证证据入口。

```bash
# 例：服务器数据实际放在 /srv/corn-demo/data
DATA_PROVIDER=parquet DEMO_DATA_DIR=/srv/corn-demo/data docker compose up -d --build
```

已有镜像可改用`up -d --no-build`。运行命令不依赖token。损坏快照返回503，缺失比较报告显示明确空态；`auto`仅在尚未配置快照时允许显示有标记的模拟行情。明确`mock`模式继续保留原演示用途。旧`uqer`provider名称兼容缓存读取，不再触发在线请求。

## 离线取数和重建

先按项目要求准备并验证Python3.12环境；以下命令从backend执行。只做Web部署不需要本节。

```bash
.venv/bin/python --version
uv sync --locked --python .venv/bin/python --extra dev --extra research --extra uqer
# 仅首次缺少响应缓存时需要在当前环境设置 UQER_TOKEN；不要写入命令示例或提交源码。
.venv/bin/python -m research.ingest --output ../var/market
# 已有responses缓存时，可完全断网、无token重新整理标准快照。
.venv/bin/python -m research.ingest --output ../var/market --offline
# 每次实验使用新的run-id；禁止覆盖已发布结果。
.venv/bin/python -m research.run --cache ../var/market --output ../var/comparison --run-id corn-2026-v2
```

SDK固定uqer1.3.39；兼容其旧版pip内部模块依赖，uqer extra固定pip23.3.2。DataAPI自身可能自动更新，首次核验为84.0.136；离线缓存使用不需要触发该更新。取数失败立即停止，不密集重试；部分缓存或hash不符也停止，防止悄悄重取。修订数据范围或合约清单须新版本记录，当前没有全市场批量下载入口。

## 本轮实验的适用范围

三类风险方法：历史分块重采样、Logistic＋Gamma、两阶段XGBoost；价格last/MA20为独立情景参照。研究合同100吨、保障价为估值日结算价95%/100%/105%、无免赔、无封顶。

限定历史内采用单独版本的20交易日回看、未来20交易日观察；训练65个有效估值日（552条研究样本）、校准15日（135条）、验证35日（246条）。跨分区标签清除360条；同日合约和条款不能跨分区。合成条款数不等于独立行情事件数。

全部方法为research_only，未指定生产默认方法，没有打开最终测试，P90不发布。历史研究不等于当前保单风险估值。长期稳定性、配对日期块不确定性、真实赔案验证和正式选型仍属后续工作；本次不补取限定范围外历史来改善成绩。
